# Davi.dev — Portfólio

Portfólio pessoal responsivo de Davi Fernandes Pedroso, feito com HTML, CSS e JavaScript puro.

## Estrutura

- `index.html` — conteúdo e estrutura semântica da página.
- `styles.css` — identidade visual, layout responsivo e animações acessíveis.
- `script.js` — menu móvel e ano automático no rodapé.

## Visualização local

Abra `index.html` em um navegador. Não há dependências nem etapa de compilação.

## Publicação

O site pode ser publicado pelo GitHub Pages selecionando a branch `main` e a pasta raiz (`/`) nas configurações de Pages do repositório.
